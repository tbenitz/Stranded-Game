# PROJECT: STRANDED — AI-Powered Space Survival & Exploration

## MASTER DEVELOPMENT PROMPT

Build a complete, professional, single-player, open-world **3D space survival, exploration, crafting, and base-building game** using Three.js, DeepSeek API, and IndexedDB.

The player is an astronaut stranded in an unfamiliar region of space after a catastrophic spacecraft malfunction.

They must survive by exploring planets, gathering resources, repairing their ship, upgrading equipment, building permanent settlements, constructing orbital space stations, and traveling deeper into an enormous procedurally generated universe.

The game should combine the exploration and discovery of No Man's Sky, survival and base construction similar to Subnautica, spacecraft management similar to Space Engineers, and an evolving AI-generated universe.

**The key distinction:** DeepSeek should dynamically create the universe's content, discoveries, stories, missions, civilizations, and encounters. The actual simulation, physics, combat, inventory, resource transactions, and player controls must run locally through deterministic JavaScript systems.

The result must be a real playable game, not a 3D scene viewer or text-based adventure.

17. Persistent worlds and player progression saved to IndexedDB.
18. Dynamic DeepSeek-driven world events.

# 2. Technology and Deployment

Build the game primarily as **one self-contained HTML file**, with CSS and JavaScript included.

Use:

- Three.js loaded from cdnjs.
- JavaScript ES modules where needed.
- WebGL rendering.
- WebGPU enhancements only when compatible and stable.
- DeepSeek API for AI-driven game content.
- IndexedDB for persistent game data.
- OPFS where useful for larger asset or world caches.
- Web Audio API for generated ambient and interactive audio.
- Web Workers for expensive procedural generation.
- Local procedural generation for planets and structures.

No React, npm installation, Python, or mandatory game server.

The game should be deployable to GitHub Pages and playable in Chrome on an 8 GB Chromebook.

If browser security restrictions prevent some features from working directly through `file://`, use GitHub Pages as the supported deployment method.

Do not claim the application works completely offline when DeepSeek or uncached external dependencies are required. Existing downloaded game content should remain playable without repeated API calls.

# 3. Game Introduction and Starting Scenario

The game begins with a dramatic but playable introduction.

The astronaut awakens inside a severely damaged spacecraft drifting near an unfamiliar planet.

The emergency systems report:

- Main propulsion damaged.
- Hyperspace drive offline.
- Life support functioning at reduced capacity.
- Oxygen reserves limited.
- Communications unavailable.
- Ship navigation database corrupted.
- Nearby space station transmitting a weak emergency beacon.

The player must begin making decisions immediately.

Their first objectives are:

1. Investigate the damaged ship.
2. Restore basic electrical power.
3. Repair the emergency oxygen system.
4. Scan the nearby planet.
5. Gather usable materials from the ship.
6. Land on the planet or use a small emergency shuttle.
7. Recover resources needed to repair propulsion.
8. Repair the ship sufficiently to reach an abandoned space station.
9. Restore the station's basic functionality.
10. Begin exploring surrounding planets.

The introductory sequence must teach the actual gameplay systems without relying on long text tutorials.

Use interactive objectives, highlighted equipment, short instructions, and optional contextual guidance.

Once the basic ship and station are operational, the player gains freedom to determine their own goals.

Do not force the player to follow one linear mission sequence forever.

# 4. DeepSeek — Dynamic Universe Director

DeepSeek is the intelligence responsible for generating and evolving the universe.

It should function as a persistent **AI Game Director**.

Its responsibilities include generating:

- Star systems.
- Planet identities.
- Biome descriptions and environmental parameters.
- Resource distributions.
- Alien ecosystems.
- Creature descriptions and behavior profiles.
- Civilizations and factions.
- Ancient ruins.
- Abandoned spacecraft.
- Space stations.
- Research discoveries.
- Missions and side quests.
- Distress signals.
- Dynamic encounters.
- Environmental events.
- Narrative discoveries.
- Unique equipment and upgrades.
- Alien artifacts.
- Long-term storylines.

DeepSeek should consider the player's history before generating new content.

For example:

If the player has repeatedly explored volcanic planets, DeepSeek might generate a mission involving heat-resistant technology, a rare mineral deposit, or an ancient mining civilization.

If the player has constructed several settlements, DeepSeek might introduce new trade opportunities, logistical problems, or construction objectives.

If the player has engaged hostile pirates, the AI might create additional pirate-related encounters or a mission involving their abandoned outpost.

## Critical Game Director Rules

DeepSeek must never directly control the authoritative game state.

The local game engine is responsible for:
- Inventory quantities.
- Health and oxygen consumption.
- Fuel calculations.
- Crafting costs.
- Combat damage.
- Ship durability.
- Resource ownership.
- Construction requirements.
- Movement and physics.
- Mission completion validation.

DeepSeek generates proposals, definitions, and event descriptions using structured JSON.

The game engine validates those outputs before applying them.

Do not allow AI responses to duplicate inventory items, invent completed objectives, bypass resource requirements, or overwrite established universe history.

The game must not require an API request for every movement, attack, crafting action, or resource collection.

# 37. Example of the Intended Experience

The player starts inside their damaged spacecraft.

Oxygen levels are falling.

- Explores alien caves.
- Collects rare minerals.
- Battles hostile creatures.
- Repairs abandoned spacecraft.
- Constructs planetary settlements.
- Builds automated mining outposts.
- Expands their orbital station.
- Develops advanced technology.
- Upgrades their spacecraft.
- Travels to distant systems.
- Encounters alien civilizations.
- Uncovers ancient mysteries.

The universe grows organically through exploration and player decisions.
